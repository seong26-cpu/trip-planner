나의 하루 — 개인정보 처리방침

시행일: 2026년 11월 5일

1. 데이터는 사용자 본인의 구글 계정에만 저장됩니다

  • 앱에 입력한 메모·일정·운동·식단·맛집 등은 사용자 본인의 구글 드라이브에 앱이 만든 「나의 하루 DB」 스프레드시트와 「나의 하루 설정.json」 파일에만 저장됩니다.
  • 앱 개발자는 별도의 서버나 데이터베이스를 운영하지 않으며, 사용자 데이터를 수집·열람·보관하지 않습니다.

2. 요청하는 구글 권한과 사용 목적

  • 기본 프로필(이메일·이름): 연결된 계정을 화면에 표시하기 위해 사용합니다.
  • Google Drive (앱이 만든 파일만, drive.file): 「나의 하루 DB」 시트와 설정 파일을 만들고 읽고 쓰기 위해 사용합니다. 사용자의 다른 드라이브 파일에는 접근할 수 없습니다.
  • Google Calendar 일정 (선택): 사용자가 연결한 경우에만, 앱에서 만든 일정·운동 계획을 기본 캘린더에 등록·수정·삭제하고 앱 화면에 일정을 표시하기 위해 사용합니다.

3. AI 기능 (선택)

사용자가 직접 발급한 Gemini API 키를 넣은 경우, 사진·질문은 해당 기능을 실행할 때만 사용자 기기에서 Google Gemini API로 직접 전송됩니다. 키는 사용자 기기와 사용자 드라이브의 설정 파일에만 저장됩니다.

4. 제3자 제공

앱은 사용자 데이터를 판매하거나 제3자에게 제공하지 않습니다. Google API 서비스에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 연결 해제와 삭제

  • 앱 「더보기 → 설정 → 구글 연결 → 해제」로 연결을 끊을 수 있습니다.
  • Google 계정 → 서드 파티 연결에서 권한을 완전히 삭제할 수 있습니다.
  • 저장된 데이터는 구글 드라이브에서 「나의 하루 DB」와 「나의 하루 설정.json」 파일을 지우면 삭제됩니다.
