☀️ 나의 하루 — 설치 가이드

일정·요리·운동·클리닝·메모를 한 곳에서 관리하는 앱입니다. 모든 데이터는 내 구글 계정 안에만 저장되며, 앱을 만든 사람의 서버나 계정과는 아무 관계가 없습니다.

📦 받은 파일
파일용도
1_나의하루_서버코드.gs내 구글 계정 안에 「내 서버」를 만드는 코드 (PC에서 1번 붙여넣기)
2_나의하루.apk안드로이드 앱 설치 파일 (아이폰은 필요 없음)

⏱ 전체 순서: ① 내 서버 만들기 (PC, 약 10분, 처음 1번) → ② 폰에 설치 (2분) → ③ AI 키 (선택, 1분)

① 내 서버 만들기 (PC · 처음 1번)

  1. PC 크롬에서 내 구글 계정으로 로그인되어 있는지 확인합니다.
  2. 1_나의하루_서버코드.gs 파일을 메모장으로 엽니다 (파일 우클릭 → 연결 프로그램 → 메모장) → Ctrl+A → Ctrl+C
  3. 크롬 주소창에 script.new 입력 → 엔터 → 새 Apps Script 프로젝트가 열립니다.
  4. 편집기 안의 글자(function myFunction() {...})를 모두 지우고 Ctrl+V → 💾 저장 (Ctrl+S)
    왼쪽 위 「제목 없는 프로젝트」를 눌러 「나의 하루」로 바꾸면 나중에 찾기 쉬워요.
  5. 위쪽 함수 칸이 「설치하기」인지 확인 → ▶ 실행
  6. 「승인 필요」 → 권한 검토 → 내 계정 선택 → 「Google에서 확인하지 않은 앱」 화면 왼쪽 아래 고급 → 「나의 하루(으)로 이동(안전하지 않음)」 → 권한 목록에서 모두 선택 ☑ → 계속
    「안전하지 않음」은 구글 심사를 받지 않은 내가 만든 스크립트라는 뜻이에요. 내 계정 안에서만 실행됩니다.
  7. 아래 실행 로그에 「✅ 설치 완료!」가 나오면 성공 (내 드라이브에 「나의 하루 DB」 시트가 생깁니다).
  8. 오른쪽 위 파란 배포 → 새 배포 → 「유형 선택」 옆 톱니 ⚙ → 웹 앱
    · 실행 사용자: 나 · 액세스 권한: 모든 사용자 → 배포
  9. 나오는 웹 앱 URL(https://script.google.com/macros/s/…/exec)을 복사 → 카카오톡 「나와의 채팅」 등으로 내 폰에 보냅니다.
🔑 웹 앱 URL은 나만 아는 비밀 열쇠입니다. 다른 사람에게 보내지 마세요. (주소를 아는 사람은 내 앱 데이터에 접근할 수 있어요)

② 폰에 설치

🤖 안드로이드
  1. 2_나의하루.apk를 폰으로 옮겨(카톡 「나와의 채팅」·구글 드라이브 등) 누릅니다.
  2. 「출처를 알 수 없는 앱」 경고 → 설정 → 이 출처 허용 켜기 → 뒤로 → 설치
    Play 프로텍트 창이 뜨면 세부정보 → 무시하고 설치
  3. 앱을 열면 연결 마법사가 나옵니다 → ① 단계 칸에 웹 앱 URL 붙여넣기 → 연결
    또는 폰 크롬에서 웹 앱 URL을 열고 마법사 ②의 「📲 앱(APK)에 연결」을 누르면 자동 연결

APK 없이 쓰려면: 폰 크롬에서 웹 앱 URL 열기 → ⋮ → 홈 화면에 추가

🍎 아이폰
  1. 웹 앱 URL을 사파리로 엽니다 (카톡에서 열었다면 ⋯ → Safari로 열기).
  2. 주소창 옆 ⋯ → 공유 (iOS 18 이하: 아래쪽 □↑) → 「홈 화면에 추가」 → 추가
  3. 홈 화면의 아이콘으로 열면 끝 — 서버는 자동으로 연결돼 있어요.

③ AI 키 (선택 · 무료)

사진으로 음식·물건 찾기, 레시피 추천, 클리닝 방법 같은 AI 기능에 필요합니다.

  1. aistudio.google.com/apikey → 내 구글 계정으로 로그인
  2. API 키 만들기 → AIza…로 시작하는 키 복사
  3. 앱 → 더보기 → 설정 → 🔗 내 서버 → AI 「넣기」 → 붙여넣기 → 확인 & 저장

키는 내 서버(내 구글 계정)에만 저장됩니다. 무료 등급 한도 안에서는 요금이 나오지 않습니다.

📅 구글 캘린더

따로 할 일이 없습니다. ①에서 「설치하기」를 허용할 때 내 구글 캘린더가 함께 연결됩니다.

다른 폰·PC에서도 쓰려면?같은 웹 앱 URL을 열거나(또는 앱에 붙여넣기) 하면 같은 데이터가 보여요.
「안전하지 않음」 경고가 걱정돼요내가 직접 만든 스크립트라서 나오는 구글 안내입니다. 코드는 내 계정 안에서만 실행돼요.

클리닝 영상을 앱 안에서 보려면?선택 기능. 설정 → 🔗 내 서버 → 클리닝 영상 「키 넣기」에 YouTube Data API 키(구글 클라우드 콘솔에서 발급)를 넣으면 돼요. 없어도 「유튜브에서 더 보기」로 볼 수 있어요.
