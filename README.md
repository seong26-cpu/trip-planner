# 여행 올인원 플래너

일정·동선 지도·예산(교통/숙소/식비/관광/그외)·항공/숙소 검색·추천 장소·번역·교통 안내·사진 일기·준비물을 한 화면에서 관리하는 웹앱입니다.

- 접속: https://seong26-cpu.github.io/trip-planner/
- 서버·로그인 없음. 데이터는 각자 기기 브라우저에만 저장됩니다.
- 저장 목록(번호별 저장/불러오기/삭제), 백업 파일 내보내기/가져오기 지원
- 내장 도시 팩: 도쿄·오사카·후쿠오카·강릉 / 내려받는 팩: `packs/` 폴더 (현재 다낭)
- 한글 도시명 입력 시 영문·공항코드·통화·언어 자동 입력 (앱 내장 도시 사전)
- 엑셀(.xlsx) 내보내기: 여행정보·예산·일정·경비·정산·예약·장소·숙소·준비물·추억 시트
- 요금·가격은 2026년 10월 웹검색 기준이며 변동될 수 있음
- 홈 "나의 여행": 여행 도시의 명소·랜드마크·시장·인기 장소 실사 사진을 Wikimedia Commons(자유 라이선스)에서 불러와 자동 로테이션 (작가·라이선스 표시, 도시별 30일 저장)
- 주 메뉴: 메모·번역/교통·경비/정산은 더보기 안에서 열기
